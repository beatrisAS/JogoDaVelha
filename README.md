**Repositório da atividade de Complementação** do aplicativo desenvolvido durante o *Mergulhando no Tema* da disciplina *Desenvolvimento de Sistemas II*.

Aplicativo interativo do clássico **Jogo da Velha**, com layout personalizado, lógica de verificação de vitória e botão de reinício.

✔ **Interface moderna e adaptada para telas pequenas**  
✔ **Turno alternado entre jogadores X e O**  
✔ **Verificação de vitória ou empate**  
✔ **Botão de reinício com reset completo da partida**  

---

## 📝 Descrição da Atividade

Complementação do projeto de Jogo da Velha:

- **Aplicar melhorias visuais e estruturais** no layout (cores, organização, responsividade)
- **Implementar verificação de vitória e empate**
- **Incluir botão de reinício funcional**
- **Destaque visual para a combinação vencedora**

---

## ✨ Recursos Implementados

✅ **Interface intuitiva e adaptável**  
✅ **Alternância automática de jogadores (X e O)**  
✅ **Detecção de vitória ou empate com alerta na tela**  
✅ **Reinício do jogo com reset de botões e placar**  
✅ **Realce da linha vencedora com cor diferente**

---

## 🛠 Tecnologias Utilizadas

- **Front-end**: XAML (MAUI)
- **Back-end**: C# (eventos e lógica de jogo)
- **Plataforma**: .NET MAUI (Multi-platform App UI)

## 🚀 Como Executar

1. **Pré-requisitos**:
   - .NET 7.0 SDK instalado
   - Visual Studio 2022 (com suporte ao MAUI)

2. **Clone o repositório**:
   ```bash
   git clone https://github.com/seuusuario/JogoDaVelha.git
   ```

3. **Execute o projeto**:

   ```bash
   dotnet build
   dotnet run --project JogoDaVelha
   ```

4. **Teste no emulador Android ou execução direta no Windows**
